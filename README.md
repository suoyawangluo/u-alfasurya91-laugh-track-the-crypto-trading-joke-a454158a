## The joke

> I bought the dip so many times my wallet now has its own support level: my credit card.

## How it works

`main.ts` (Node 22) builds the joke from a setup and a punchline, validates the
gate (1–200 characters, single line, non-blank), and writes it to
`/output/entry.txt`, then reads it back and prints its sha256.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
